# Starting kdb+ – A Tutorial

## Overview

This quickstart guide introduces kdb+, a combined database and programming language system, along with q, its integrated general-purpose programming language. The material targets independent learners and covers installation, environment setup, inter-process communication, tables, and typical database structures.

## What is kdb+?

The kdb+ system comprises two components:

- **kdb+**: the database system (short for "k database plus")
- **q**: the general-purpose programming language integrated with kdb+

## Getting Started

Prospective learners without licensed kdb+ access can download and install the free system. The q console provides immediate command entry and result display—sufficient for tutorial work.

As proficiency develops, developers may transition to KX Developer, an interactive development environment, or its enterprise variant, Kx Analyst.
